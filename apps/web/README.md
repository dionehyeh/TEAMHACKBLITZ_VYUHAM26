# BizContext AI - Web Application

Next.js frontend application for BizContext AI.

## Features
- Unified workspace navigation (Knowledge, Asset Storage, Messages, Projects, Tasks, Tickets, Meetings, Agents)
- Notion-style knowledge block editor
- AI assistant chat interface with citations and source verification
- Approval queues and interactive browser agent controls
- Modern, high-performance UI components

## Development

```bash
bun dev
```
